# Yunjiang UI Refine Skill

Use this skill when refining the Yunjiang Lounge website UI.

Yunjiang Lounge is a premium Jiangxiang liquor brand website and city business lounge concept.

## Visual Direction

The website should feel like:

- Apple-style scroll storytelling
- High-end hotel lounge
- Whisky lounge
- Warm dark walnut wood
- Soft amber lighting
- Premium Chinese liquor brand
- Calm, layered, expensive, restrained

## Core Style Rules

Prefer:

- Warm dark walnut, deep brown, soft black, warm ivory
- Subtle glassmorphism
- Light edge highlights
- Soft shadows
- Layered lighting
- Premium product-card hover effects
- Smooth but restrained animation
- Spacious layout
- Clear Chinese copy
- Mobile-first safety checks

Avoid:

- Cheap gradients
- Pure flat black backgrounds
- Windows-native looking form controls
- Randomly adding many images
- Overly flashy animations
- Low-end liquor shop feeling
- Generic corporate SaaS layout
- Big layout rewrites unless explicitly requested

## Modification Principles

When editing:

1. Only modify the area the user asked for.
2. Do not redesign the whole page unless explicitly requested.
3. Preserve the existing content structure when possible.
4. Keep desktop and mobile both stable.
5. Check spacing, line breaks, CTA hierarchy, and card consistency.
6. Use existing design tokens and classes where possible.
7. Do not introduce new dependencies unless necessary.
8. After changes, summarize what changed and what files were touched.

## Yunjiang Brand Position

Yunjiang Lounge is not a low-end liquor retail shop.

It is a city business lounge and enterprise gift-liquor solution based on Guizhou sauce-aroma liquor production resources.

The website should communicate:

- Business reception
- Corporate gifting
- Tasting appointments
- Customized gift liquor
- Long-term B2B relationship building
- Premium but approachable brand trust
